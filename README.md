# Pupil

A Duolingo-like app modeled after [amosblomqvist/learn](https://github.com/amosblomqvist/learn), based on the zone of proximal development.

### Rough User Journey

- User enters something they would like to learn
    - LLM asks questions and iterates on syllabus scope and duration
- Initial assessment - LLM asks questions to assess user’s level
    - Also based on other courses that user has previously completed
- Refine syllabus
- Teach-assess loop
